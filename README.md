# Кроличий спуск

Небольшой мобильный 3D-прототип на JavaScript и Three.js. Первая лесная карта — цельный маршрут длиной около 3 км. Сборщик проекта не нужен.

## Запуск в Windows

1. Открой PowerShell в папке `rabbit-hill`.
2. Выполни `.\server.ps1`.
3. Открой в браузере `http://localhost:8000`.
4. Чтобы выключить локальный сервер, нажми `Ctrl+C` в окне PowerShell.

Если Windows блокирует скрипты, запусти его так:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

## Управление

- В меню нажми **Играть**.
- Удерживай кнопку натяжения и отпусти, чтобы запустить кролика.
- Во время заезда веди пальцем по экрану влево или вправо.
- На компьютере для запуска можно использовать пробел, для поворота — стрелки или `A`/`D`.

## Где что находится

- `src/game.js` — состояние игры, запуск и физика.
- `src/config.js` — баланс, цены, параметры холмов и расположение бонусов.
- `src/track.js` — игровой маршрут, препятствия и пружинящие площадки; Blender-карта движется вместе с трассой.
- `src/assets.js` — реестр ассетов, загрузка GLB-моделей и запасные заглушки.
- `src/rabbit.js` — анимации кролика.
- `src/slingshot.js` — натяжение тяг, движение чашечки и пружинящий запуск.
- `src/effects.js` — лёгкая мягкая контактная тень под санями.
- `src/sky.js` — фоновые облака и летающие птицы.
- `src/ui.js` — меню, HUD, прокачка и результаты.
- `src/texts.js` — игровые надписи и сообщения.
- `models/rabbit.glb` — модель кролика с отдельными поворотными узлами для ушей, лап и головы.
- `models/pumpkin-cart.glb` — тыквенные сани; внешний вид меняется на каждом пятом уровне.
- `models/slingshot.glb` — рогатка с четырьмя внешними ступенями (0–3); её тяги и чашечка анимируются при запуске.
- `models/forest-map.glb` — рельеф, земляная трасса и крупные ориентиры Blender-карты на длину 3 км; лесная растительность остаётся инстансированной в Three.js для быстрой отрисовки.
- `models/forest-map.blend` — редактируемая Blender-сцена карты с деревьями, грибными полянами, ручьём, мостом и воротами.
- `models/forest-map-preview.png` — рендер лесной карты из Blender.
- Покупки прокачки показаны пятью блоками: один блок заполняется за одно улучшение.
- `models/pumpkin-cart-level6-preview.png` — вид тыквы после всех шести визуальных ступеней.
- `models/rabbit-and-pumpkin-cart.blend` — исходная сцена Blender для дальнейшего редактирования.
- `models/slingshot.blend` — исходная сцена рогатки в Blender.
- `models/preview.png` — картинка моделей для быстрого просмотра.
- `models/slingshot-preview.png` — картинка рогатки для быстрого просмотра.
- `style.css` — оформление и адаптация под мобильный экран.

Прогресс и рекорд хранятся в `localStorage` браузера. Three.js загружается с jsDelivr CDN, поэтому для открытия страницы нужен интернет.

## Публикация для игры по ссылке

Игра не требует сервера или сборки. Чтобы открыть её по общей ссылке:

1. Создай **публичный** репозиторий GitHub с именем `rabbit-hill-game`.
2. Загрузи содержимое этой папки в корень репозитория — файл `index.html` должен быть в корне.
3. В **Settings → Pages** выбери **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. Через минуту страница появится по адресу `https://ТВОЙ-ЛОГИН.github.io/rabbit-hill-game/`.

Открой ссылку на iPhone или iPad в Safari. Three.js загружается с jsDelivr CDN, поэтому для игры нужен интернет. Прогресс сохраняется отдельно в браузере каждого игрока.
